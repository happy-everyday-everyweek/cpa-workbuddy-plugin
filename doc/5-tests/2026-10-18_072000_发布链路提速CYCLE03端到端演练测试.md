## 3. TASK-007 · 松散对象整理（阻断）

### 3.1 执行结果

```text
$ git gc --prune=now
fatal: sha1 file '.git/objects/pack/tmp_pack_iiPNsS' write error. Out of diskspace
fatal: failed to run repack
```

### 3.2 环境事实

```text
F:  24G  已用 24G  可用 20K  100%
.git  6.8G（4.1GB pack + 2.64GB 松散对象 4936 个）
```

gc 中途留下的 `tmp_pack_iiPNsS`（2.45GB）已删除，磁盘恢复 2.3G 可用、`.git` 恢复 6.8G。

### 3.3 既有损坏

```text
warning: no corresponding .pack: .git/objects/pack/pack-1a7d77cb9f3f1acb88825826d95e02b2263281e9.idx
warning: no corresponding .pack: .git/objects/pack/pack-eb7753859f9adece842b59a0460fdc8e83c24490.idx
$ git fsck --no-dangling
missing blob f189af70c27ca1f95531bcc6cc236a38ee58427a
missing tree 55a664922239f160320f7db8eb73347f202c9ab7
```

两个孤儿 idx 的日期为 2026-09-30 / 2026-10-07，属既有状态。`git cat-file` 可正常读出这两个对象，说明是索引层损坏而非数据丢失；`git log` / `git status` / `git push` 均正常。

### 3.4 处置

按计划阻断条件「`git fsck` 报错时停止」，**不执行任何 gc / repack / 历史重写**，仓库保持原状。恢复条件：F: 盘可用 ≥5GB 后重跑，先清理孤儿 idx 再 gc。
