## 4. TASK-003b · 原子推送

### 4.1 首次提交失败与修正

首次尝试用 `git commit -- <path>` 提交，因工作树中缓存文件仍在，`release-assets` 的删除没有进入提交（只提交了 4 个文件）。改用 `git rm --cached` 后立即提交（不带路径），98 个删除才进入提交。

随后为满足「同一次提交」要求，执行 `git reset --soft 613f1e4` 把两次提交合并为 `7bb50e7`（102 文件：4 改动 + 98 删除）。该提交的 tree 与远端并行会话已推送的 `9d21979` **完全一致**（`934be5d0…`），因此本地 `git reset --mixed origin/main` 对齐，无内容丢失。
