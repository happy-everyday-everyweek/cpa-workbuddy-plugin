## 1. 测试目的

验证三件事是否真实成立：

1. 分支 push 只执行 12 个 Test job，构建与发布 job 被跳过。
2. 仅含 `doc/` 路径的 push 不创建 workflow run（`paths-ignore` 生效）。
3. 顶层 `concurrency` 配置能被 GitHub 接受且不影响 run 正常完成。

## 2. 改动内容

| 位置 | 改动 |
| --- | --- |
| `on.push` | 新增 `paths-ignore: ["doc/**", "skills/**", "release-assets/**", "**/*.md"]` |
| 顶层 | 新增 `concurrency.group = build-${{ github.workflow }}-${{ github.ref }}`、`cancel-in-progress = ${{ github.event_name == 'push' && github.ref_type == 'branch' }}` |
| `build` job | 新增 `if: github.event_name == 'workflow_dispatch' \|\| startsWith(github.ref, 'refs/tags/')` |
| `build-cross` job | 同上 |
| `release` job | 未改动（原有 `if` 已限定 dispatch 带 version 或 tag，push 场景天然不成立） |

## 3. 执行步骤

1. 本地 YAML 解析校验（`yaml.safe_load`）。
2. `git commit` + `git push origin main`，触发代码路径 push run。

4. `GET /actions/runs/{id}/jobs?per_page=100` 统计 job 名称与结论。
5. 推送仅含 `doc/` 改动的 commit，比对 `total_count` 与 run 列表。
